# Valentino — цветочный интернет-магазин (сестринский бренд DonPion)

Тот же код, что в [`../server`](../server)/[`../client`](../client)/[`../admin`](../admin)
(см. [корневой AGENTS.md](../AGENTS.md) за архитектурой, эндпоинтами и
соглашениями — они одинаковы для обоих брендов), но отдельный, полностью
независимый деплой под брендом Valentino. Ничего общего в рантайме с
DonPion: отдельная БД, отдельные процессы, отдельные порты.

| Папка | Порт (dev и prod) | PM2-процесс |
|---|---|---|
| `server/` | 4200 | `valentino-server` |
| `client/` | 3001 | `valentino-client` |
| `admin/` | 5174 (dev; prod — статика через Nginx) | — |

- **MongoDB:** своя база `valentino-shop` на том же mongod (Docker-контейнер
  `local-mongo` на VPS) — физически рядом с базой `flower-shop` (DonPion), но
  логически полностью отдельная. Каталог (категории/товары/характеры/
  настройки/филиалы) изначально склонирован из продакшен-базы DonPion
  (`mongodump`/`mongorestore` с `--nsFrom=flower-shop.* --nsTo=valentino-shop.*`
  на VPS) — после клонирования это независимая копия, правки в одной базе не
  трогают другую.
- **Фирменные цвета:** тиффани + белый. Токены в `tailwind.config.ts`
  (`client/` и `admin/`) называются так же, как в DonPion (`hermes` —
  единственный акцент, `navy` — фон хедера), только значения hex другие —
  см. комментарии прямо в конфиге. Не переименовывай токены без необходимости
  перекрасить каждое место использования (`bg-hermes-500`, `bg-navy` и т.д.
  разбросаны по полутора десяткам компонентов).
- **Деплой на VPS:** живёт в том же git-чекауте, что и DonPion —
  `/var/www/donpion/valentino/*` (имя папки — историческое, не переименовано
  специально, чтобы не трогать существующие nginx/PM2 пути DonPion). Свой
  `ecosystem.config.js` в этой папке — `pm2 start valentino/ecosystem.config.js`
  из `/var/www/donpion` (или `cd valentino && pm2 start ecosystem.config.js`).
- **Телеграм-бот, соцсети, email, домен, GA — не настроены.** В коде
  оставлены явные плейсхолдеры (`VALENTINOUZ_BOT`, `valentino.uz`,
  `G-REPLACE_WITH_VALENTINO_GA_ID`, ...) — см. список в истории чата/PR, где
  заводился этот бренд, и замени на реальные значения перед запуском в прод.
