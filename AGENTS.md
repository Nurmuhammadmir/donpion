# DonPion — цветочный интернет-магазин

Монорепозиторий из трёх независимых приложений — подробности и команды
запуска смотри в [README.md](README.md). Каждое приложение живёт в своей
папке со своим `package.json`, зависимостями и конфигом; ничего не
устанавливается и не собирается из корня репозитория.

| Папка | Что это | Стек | Порт |
|---|---|---|---|
| `server/` | Backend REST API | Node.js + Express + MongoDB/Mongoose | 4100 |
| `client/` | Витрина для покупателей | Next.js 14 (App Router) + next-intl (RU/UZ) + Tailwind CSS | 3000 |
| `admin/` | Панель администратора | Vite + React + Tailwind CSS | 5173 |

`client` и `admin` не подключаются к MongoDB напрямую — оба общаются только
с `server` по HTTP.

## Разработка

Серверы (`server`, `client`, `admin`) уже запущены отдельными процессами в
режиме разработки — не нужно запускать `npm run dev` вручную, если только
явно не требуется перезапуск.

## Код

- `client/` использует App Router с сегментом `[locale]` — все новые
  страницы должны идти через `next-intl` (`setRequestLocale`,
  `getTranslations`/`useTranslations`), локализация RU/UZ обязательна для
  новых пользовательских текстов (`client/messages/ru.json` и `uz.json`).
- Компонент, использующий `onClick` или любой другой обработчик, обязан
  быть `"use client"` — иначе сборка падает с ошибкой передачи обработчиков
  в Server Component.
- `admin/` — обычный Vite SPA, без i18n.
- `server/` — Express + Mongoose; ошибки валидации/дублей должны попадать в
  `errorHandler.js` и возвращать понятные 400, а не голый 500.
